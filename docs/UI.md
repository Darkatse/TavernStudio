# 界面与动效

Studio 的外壳要美观、克制、快。外壳是作者工作的框架，不是主角：预览里显示的是作者的主题，外壳不与它争色。

设计前先查 [References](References.md#界面与动效) 里的实现。本文记录采纳的结果，是界面规则的唯一依据。第三方的设计 Skill 不直接安装，采纳的规则写进本文。

## 1. 布局

- **宽屏**（≥ 768px）：左侧 Agent 栏，右侧工作台。两者是浮在底色上的圆角面板，相隔 8px。Agent 是主要的编写者，所以放在最先看到的位置；这与 v0、Lovable 的布局一致。
- **Agent 栏**默认 380px，可以在 320px 到一半宽度之间拖动，也可以收起。窗口缩放时它保持像素宽度，工作台吸收变化。收起时它与窗口边缘的间距随它一起收走，里面的内容不能再经 Tab 进入。
- **工作台**有预览和代码两个标签。两个面板都保持挂载：切换视图不会销毁正在运行的预览和编辑器状态。
- **预览舞台**：设备框是设备的整块屏幕，只整体缩放以放进舞台，从不放大；下方标注设备、页面的视口尺寸和缩放比例。
  - 移动设备是 iPhone 17：屏幕 402 × 874，圆角 62。上下画出状态栏与 home indicator，页面只占两者之间的安全区，得到 402 × 778，与 TT 的 iOS 宿主把 WebView 限在安全区相同。
  - 状态栏照 iOS 27 画：时间、信号、Wi‑Fi 与电池的位置和形状，都在 Xcode 的 iPhone 17 模拟器截图上量出并拟合；图形由 Studio 自己绘制，不用 Apple 的素材。不画灵动岛。
  - 两栏只显示屏幕的比例：不接收输入，不进截图。每一栏取页面相邻那条边的颜色：在离边几个像素处，把那一点的各层从下往上叠起来，背景图取它落在这一栏高度内那部分的平均色。iOS 26 的 Safari 也是取贴边元素的颜色给状态栏着色。
  - 栏上的字形在这个颜色的相对亮度高于 0.179 时取深色，否则取浅色，这是 TT 原生宿主的规则。
- **窄屏**：一次显示一个面板（Agent、预览、代码），由底部的分段控件切换，隐藏的面板保持挂载。窄屏默认预览移动设备。

## 2. 组件

- 组件层是 shadcn（Base UI 版）与 Tailwind v4。组件源码复制进仓库，归 Studio 所有，可以按本文改写；不以 npm 包的形式依赖组件库。
- 取用顺序：shadcn 官方组件 → Fluid Functionalism（Base UI 版）→ beUI。
- Beautiful UI 只作为 Agent 界面的交互参考：Thinking、Streaming Text、Tool Chips、Approval Card、Task Rows、Diff Table、Code Block、Agent Screen。
- Animate UI 采用 MIT + Commons Clause，与 AGPL 不兼容：只参考做法，不复制代码。
- 引入组件时：动效改写为 §4 的档位，数值换成 §3 的 token，并在文件头注明来源与许可。
- 组件的 `className` 只用于布局，视觉差异写成变体。组件自己的布局默认值（如按钮的高度、内边距）写在 `[:where(&)]:` 下，优先级为零，`className` 设同一属性时总能生效，与样式表里的先后无关。因此不需要 tailwind-merge。
- 禁用的按钮保持可聚焦，用 tooltip 说明为什么不可用。
- 选择类控件：
  - 切换面板内容的用 Tabs，从几个选项里选一个的用 SegmentedControl（单选组），两者共用凹陷的轨道和滑动的滑块；
  - 表单里一排放不下全部选项的字段用 Select，不用原生 `<select>`：触发器与输入框同一外观，列表从触发器下方展开（[Decisions](Decisions.md)）。
- 弹出列表（菜单、自动补全、Select）共用一种浮层和行样式。单选的选项以对勾标出当前项；性质不同的选项放在分隔线下，例如推理强度的"关闭"、服务里的"自定义"。
- Transcript 的结构先参考 TT 应用内助手：React 组件，宿主能力经 `actions` 注入。
- Fluid Functionalism 与 beUI 的组件依赖 Motion，取用时把动效改写为 §4 的 CSS 档位。
- 不引入 cmdk 与 `@shadcn/react`：前者带 Radix 原语，后者把组件逻辑放进了 npm 包。
- 文件树用 headless-tree（MIT）加自绘的行；diff 用 `@codemirror/merge`（MIT）。
- 图标用 Lucide。在 Lucide 图标之间代表 Studio 时，例如窄屏面板切换里的 Agent，用标志的线性版（`brand/brand-icon`）：线宽、圆头与 Lucide 相同，颜色跟随文字。彩色的标志只用于品牌本身，例如 Agent 栏的标题。

## 3. 视觉 token

起点取自 Fluid Functionalism。token 全部定义在 Tailwind v4 的 `@theme` 中，Tailwind 的默认色板与刻度已移除，组件里不写裸值。

| 项 | 规则 |
|---|---|
| 密度 | 两档：默认 36px，紧凑 28px。按钮、输入框、选择器与列表行同高，弹出列表的行与触发器对齐。密度按区域设定（`data-density`）：面板标题栏、文件树、编辑器工具栏和检查器用紧凑档。紧凑档只在精确指针（`pointer: fine`）下生效，触屏一律用默认档，触控目标因此不小于 36px |
| 字体 | 拉丁字符用 Inter 可变字体（自托管，按 `unicode-range` 只下载用到的子集）；中文回落到系统字体；代码用系统等宽字体栈。字号按用途分六个角色（display、title、subtitle、body、caption、micro），不按大小挑。Transcript 与 Markdown 的字号行高在 P1a 实测 14/22 与 13/20 后定稿；中文段落行高不低于 1.6 |
| 可编辑字段 | 触屏设备上不小于 16px，避免 iOS Safari 聚焦时缩放页面 |
| 文字颜色 | 只有 foreground 与 muted 两种。红色只表示错误。不用透明度区分层级 |
| 强调色 | 琥珀色，只用于焦点、主要操作和品牌标志，其余一律用带一点暖意的中性灰阶 |
| 表面 | 由后到前：底色、凹陷、面板、浮层。浅色模式靠阴影区分层级，深色模式靠逐级变亮。次级按钮用浮层色，放在哪一层上都不比它暗，否则在浮层上像凹进去的。输入框用面板色，在浮层上呈凹陷，这是字段本来的样子 |
| 圆角 | 同心：内圆角 = 外圆角 − 内边距 − 边框 |
| 流式文本 | 不用 `text-wrap: balance` 或 `pretty`，避免已输出的行重新折行。静态的说明文字可以用 `pretty` 避免孤字 |
| diff | `--color-diff-add`、`--color-diff-del` 两组底色，配 `-fg` 前景色。低彩度，与 danger 区分开。+/− 符号与删除线同时出现，不只靠颜色 |
| 语法高亮 | 十个 `--color-syntax-*`，深浅色各一套，每个对应哪些 Lezer tag 写在样式表注释里。CodeMirror 主题直接引用这些 CSS 变量 |
| 遮罩 | `--color-backdrop` 压暗对话框背后的内容；看大图用更深的 `--color-scrim`，深浅色相同。不加模糊，因为背后常是预览 iframe |
| 对比度 | 文字与它可能落在的每一种底色之间，对比度不低于 4.5:1，凹陷色与 diff 底色也算在内 |
| 状态 | 运行中、已取消、失败、interrupted 四种状态只用 foreground、muted、danger 三种颜色，并配上图标和文字 |
| 预览上的标记 | Studio 画在预览上的标记用强调色，例如 Agent 光标、检查器的选框。作者的主题可能正被改坏，标记不能依赖它 |

只经 `var()` 读取的 token，例如 diff 和语法高亮，放在 `@theme static` 中：Tailwind 只输出被工具类用到的变量。

深浅色跟随系统，也可以手动切换：
- 手动设置存在 cookie `studio-scheme` 里，由 `index.html` 的内联脚本在首帧之前读出，IndexedDB 来不及应答；cookie 丢失时回到跟随系统。界面语言同样存在 cookie 里，见 §6。
- 切换的瞬间冻结所有过渡，避免逐个元素出现颜色渐变。

## 4. 动效

动效用来传达状态变化，不作装饰。高频使用的界面保持克制。

| 档位 | 进入 | 退出 | 用于 |
|---|---|---|---|
| fast | 80ms | 60ms | hover、淡入淡出、tooltip、焦点环 |
| moderate | 160ms，临界阻尼，无回弹 | 120ms | 下拉、标签页、抽屉、短距离位移 |
| slow | 240ms，轻微回弹 | 160ms | 对话框、大面板 |

- 越大的东西动得越慢。组件只引用档位，不写具体时长。
- 退出比进入快一档，用 ease-out 补间，不用弹簧。
- 只动 `transform` 与 `opacity`，不动 `top`、`left`、`width`、`height`。
  - 原因：前两者由合成线程完成，不触发重新布局和绘制。
  - 这在 Studio 里尤其要紧：预览与 Studio 同源，共用一个主线程，vendor 繁忙时，这类动画仍然流畅。
  - 例外：选择类控件的滑块同时过渡 `width`，因为圆角和阴影没法用缩放表达。
    - 它是绝对定位的小元素，实测每帧的 Layout 不到 0.1 ms。
    - 已知的失效方式：主线程被 vendor 占住时，宽度会落后于位移，等主线程空出来才跳到终值。
    - 选项宽度不等、又会在 vendor 繁忙时切换的地方，用 `fill` 让各项等宽。
  - 例外：Agent 栏收起和展开时，两栏的分界逐帧移动，工作台随之重新布局。
    - 工作台的宽度变化没法用变换表达，缩放会压扁文字和圆角。Agent 保持展开时的宽度滑出、滑入，内容不重排；预览 iframe 的视口不变，只改缩放。shadcn 与 Fluid Functionalism 的侧栏也是这样做的。
    - 实测每帧的 Layout 不到 0.4 ms、样式计算不到 2 ms，帧间隔保持 16.7 ms；打开代码视图时相同。
    - 已知的失效方式与滑块相同。
- 按元素尺寸排布的内容与尺寸在同一帧更新，例如预览舞台里的设备框：尺寸变化在绘制前提交，不落后一帧。
- 折叠：
  - 高度瞬间变化；
  - 内容用透明度动画（可以加 −4px 的位移），moderate 档进入、fast 档退出；
  - Transcript 和文件树里不对高度做动画。
- 循环动画只有 spin 与 indeterminate 两种。不用 shimmer，因为它动的是 `background-position`。
- 品牌标志是唯一的装饰动效，只在指向它时出现，动态参照 Anthropic 官网的字标：
  - 猫眨一下眼，时长取 slow 档。眼睛闭上之后（fast 档），原处的标题淡出，Tavern Studio 的字母从挤在标志旁的位置散开、淡入。指针只是经过时，标题不闪动。
  - 散开用两倍 slow 档的时长：slow 档的弹簧在前四分之一就走完大半，散开会一闪而过。字母在散开近半时才淡入，挤在一起的样子看不到。
  - 离开用两倍 slow 档退出的时长。字母先在原处淡出，等 fast 档之后才向标志收拢，同样不让挤在一起的样子露出来；字母淡去后标题回来。
- 图标交换：两个图标放在同一格，进入用完整档，离开用退出档。离开不由 Base UI 标记时（hover 或状态切换），在隐藏的一侧加 `motion-fast-exit`：过渡取目标状态的时长与缓动。
- 折叠触发器的箭头用 transform 旋转，moderate 档；减少动态效果时直接切换。
- 动画可以中途打断，并从当前状态平滑返回。
- 键盘导航不加动画。
- 用户开启"减少动态效果"时：
  - 去掉位移、缩放和布局动画；
  - 保留透明度与颜色渐变；
  - indeterminate 停止，spin 放慢。
  
  动效变少、变轻，但不是完全没有。
- 动效不触及预览 iframe。iframe 里是 vendor 的完整布局，对它做尺寸动画会让 vendor 逐帧重排。切换 Device 本来就会重载 View。

**实现**：默认用 CSS。
- 每个档位是一个工具类（`motion-fast`、`motion-moderate`、`motion-slow`），提供时长与缓动，并让退出自动快一档；组件只声明要过渡的属性。
- 几种固定的配方也是工具类：
  - `motion-popup`：浮层的出现与消失，从锚点缩放淡入；
  - `motion-fold`：折叠内容；
  - `motion-toast`：Toast 的进入与离开；
  - `motion-zoom`：从打开它的元素放大，关闭时缩回原处。打开者经 `--zoom-x`、`--zoom-y`、`--zoom-scale` 给出起点；减少动态效果时只淡入淡出。
  
  后两者都是 moderate 进入、fast 退出，即 160 ms 弹簧进入、60 ms ease-out 退出。位移距离取自 `--motion-fold-offset`、`--motion-toast-distance`，减少动态效果时归零。
- Base UI 用 `data-starting-style` / `data-ending-style` 驱动 CSS 过渡，进入、退出和中途取消都由它处理。
- Agent 栏的分界：面板库一次设定两栏的 `flex-grow`，Web Animations 从旧值动画到它设定的值，面板库仍是唯一的写入者。动画自行结束，之后的拖动和窗口缩放不受影响。它是最大的移动物体，用 slow 档：展开带轻微回弹，收起用退出档。切换按钮的箭头翻转，moderate 档。
- 会挂起的内容（按需加载的代码，或经 `use()` 读取的数据）第一次出现时，不落在空的 fallback 上：由一次非紧急更新带进已经挂好的 Suspense 边界，内容到齐后与它所在的界面在同一次提交里出现。
  - 由事件带出的，用 `startTransition`，例如打开设置对话框、回滚确认框；由 store 的状态带出的，用 `useDeferredValue`，例如第一条消息带出的 Transcript、第一处待采纳的修改带出的采纳徽标。
  - 否则会先提交空的 fallback：浮层错过 Base UI 标出的起始状态，进入动画就没有了；React 还会把 fallback 之后的内容压后至少 300 ms 才揭示。
  - 能预见时先取代码：指向或聚焦设置按钮时取设置，开始写消息时取 Transcript。
- 弹簧曲线用 CSS `linear()` 表达，由 `apps/studio/scripts/springs.mjs` 生成。
- 参考库大多基于 Motion，复制它们的组件时，把动效改写为 CSS 档位。
- 出现 CSS 做不到的需求（手势驱动、需要速度连续的拖拽）时，再引入 Motion 并按需加载，同时记入 [Decisions](Decisions.md)。

## 5. 交互

- **列表高亮**（文件树、命令面板、菜单）：只有一个高亮块，随指针移动。指针在某一项内，就高亮这一项；否则高亮最近的一项。点击落在空隙里时，交给高亮项处理：高亮的就是点击会命中的。以下列表不用这种高亮：误点代价高的、只有部分项可点的、内容会自行移动的（例如实时日志）。
- **焦点**：预览里的页面不能从 Studio 拿走焦点（[Architecture §4](Architecture.md#4-运行时)）。焦点环只在 `:focus-visible` 时显示。菜单和命令面板以高亮行作为焦点指示。组合框的输入框保持 DOM 焦点，用 `aria-activedescendant` 指向当前行。
- **滚动条**：触屏设备用原生滚动。桌面用细滚动条。
- **只在 hover 时出现的操作**：在触屏和键盘焦点下也必须可见。
- **破坏性操作**：
  - 不用红色，因为红色只表示错误；
  - 按钮写明动作，例如"回滚到此处""丢弃"；
  - 经 AlertDialog 确认，确认框列出会受影响的内容。
- **加载**：
  - 短于 300 ms 的加载不显示提示；
  - 内容形状已知时，用静态骨架；
  - 时长未知时，用 indeterminate 细线。
- **空状态**写明下一步该做什么。
- **首次使用**：
  - Agent 面板的欢迎页列出还差的步骤：新建项目、连接模型，顺序不限。完成的一步打勾，并写明用的是哪个项目或模型；
  - 两步都完成后，换成适合当前项目的示例请求。点一下填进输入框，不直接发送；
  - Studio 读出上次的项目和模型设置之前，这些步骤不显示，免得已完成的一步先闪出来；
  - 输入框始终可以输入。不能发送时，一有内容就在输入框上方写明原因；缺模型时，输入框底部的模型按钮变成连接模型的入口。
- **推理强度**（[Agent §2](Agent.md#2-模型接入)）：
  - 输入框底部、模型按钮之后的一个按钮：灯泡加档位名。只在会思考的模型下出现，随按需加载的部分淡入，与打开"推理模型"时相同。
  - 按钮贴合当前档位名，其余档位名脱离文档流叠在它上面。灯泡只画了图标框一半的宽度，自带留白，所以它与文字的间距取 4px，看上去与其他图标和文字的间距一致。
  - 换档时新名字滚入：升档自下而上，降档自上而下，位移随"减少动态效果"归零。灯泡的填充随档位变深，只过渡透明度。
  - 菜单从高到低列出模型支持的档位，"关闭"在分隔线下。指向或聚焦按钮时开始读取档位，打开时通常已经就绪。
  - Run 进行中按钮禁用，提示 Run 结束后再调整：档位在 Run 开始时读取。
- **错误**：
  - 在原处显示原文，并提供重试；
  - 需要用户处理的错误，不用会自动消失的 toast。
- **Toast**：
  - 宽屏在右下角，窄屏在底部面板切换器之上；
  - 最多同时显示三条，始终展开成列表，不叠成一摞，因为叠放需要对高度做动画；
  - 需要处理的错误立即播报，并一直留到用户关闭；
  - F6 进入通知区，Esc 关闭当前那一条。
- **编辑器的文件标签**：
  - 标签可关闭、会溢出，所以不用凹陷轨道加滑块的样式；
  - 当前标签与内容区使用同一种表面色，连成一体；
  - 脏点与关闭按钮在同一格里交换；
  - 溢出时横向滚动。标签栏放不下细滚动条，所以不显示滚动条：滚轮转为横向，切换标签时滚到可见处。
- **输入法**：中文输入法组字期间，按 Enter 不发送。
- **色样**：颜色值前有一个色样。代码编辑器、待采纳修改的文本差异与值表用同一条判断（`ui/swatch.ts` 的 `isColor`）和同一种外观（样式表的 `swatch`）。
  - 算作颜色的，是自带取值的完整颜色：CSS 里的颜色值，或 JSON、JS 字符串的全部内容。含 `var()`、`env()`、`attr()` 的值不算，`inherit`、`currentcolor` 这类关键字也不算，它们是什么颜色要看所在的元素。
  - 半透明的颜色画在棋盘格上，不会被看成更浅的颜色。
  - 色样只读，没有悬停预览和取色器，代码文字也不按颜色着色（[Decisions](Decisions.md)）。
  - 文本差异里删除的行没有色样：删除的块由 `@codemirror/merge` 自己绘制。
- **导入文件**：文件树标题栏的导入按钮和右键菜单的"导入文件…"打开系统的文件选择，导入到当前文件夹；也可以把文件从系统拖进文件树，高亮的文件夹就是文件会落入的位置。
  - 只接受文件。拖进来的文件夹和树里自己的行不导入。
  - 与已有文件同名时，经 AlertDialog 确认替换，列出会被替换的文件；与文件夹同名时报错。
  - 导入后展开目标文件夹，打开第一个文件。
- **图片与字体**：编辑区打开不是文本的文件时，按文件开头的签名显示它，与 Agent 的 `read_file` 同一种判断。
  - 图片放在棋盘格上，不超出内容区。棋盘格与色样共用一种图案（样式表的 `checkerboard`）。
  - 字体显示样张，只画字体画得出的行，缺的字留空，不用别的字体补。
  - 下方居中写格式、尺寸与大小。字体在这之上列出各类文字的字形数，没有的一类用 muted。
  - 最后是它在预览里的 URL 和复制按钮；没有 Mount 放置它时写明预览里没有它。
  - 其他文件显示"无法打开"，写明能打开哪些文件。
- **看大图**：点缩略图打开，图片从缩略图处放大，按原尺寸显示，不超出视口；点任意处或按 Esc 关闭，缩回原处。
- **上下文用量**：输入框底部、推理强度之后的小圆环与百分比，随按需加载的部分淡入，只在对话已有计数时出现。菜单里写明已用多少、何时自动压缩，提供立即压缩和设置阈值。
- **改名**：文件、项目和对话都在原位改名，共用 `ui/name-field`。项目和对话的名称按钮共用 `ui/name-button`，菜单里的改名流程共用 `useRenaming`。
  - Enter 提交，Esc 取消；离开字段时提交，名称有问题或为空时取消。问题显示在字段下方。
  - 进入时什么都不移动：文字留在原处，字段的边框淡入。项目名的按钮留在字段下面占位，宽度取原名与输入中较宽的一个；它的箭头淡出，文字颜色过渡到正文色。退出时立即复原。
  - 项目名称去掉首尾空格，不能为空，也不能与别的项目重名。

## 6. 文案与本地化

Studio 的界面说中文和英文。

- **语言**：设置里三选一：跟随浏览器、中文、English。跟随浏览器时，取 `navigator.languages` 中第一个 Studio 会说的语言，都不会时用英文。切换立即生效，不重载。手动的选择存在 cookie `studio-locale` 里，首次渲染之前读出，并设置 `<html lang>`（中文为 `zh-CN`），它同时决定中文字形回落到哪种字体。
- **文案的位置**：每个功能目录有一个 `messages.ts`，用 `defineMessages` 并排写中文和英文。按需加载的部分有自己的文案模块，与它一起加载，例如 `agent/run-messages.ts` 随 Transcript、`agent/model-settings-messages.ts` 随设置对话框，首屏只带首屏的文案。组件经 `useMessages` 取当前语言的文案，渲染之外的代码（如导出结束时的 toast）经 `messagesNow` 取。几处共用的词（取消、关闭、重试……）放在 `i18n/common.ts`。
- **组件里不写文案**：用户能看到或读屏器能读到的文字，包括 `aria-label`、tooltip、toast、占位文字和 CodeMirror 的界面短语，都来自 `messages.ts`。
- **两种语言一一对应**：英文必须和中文有相同的键；中文是函数的地方，英文也是函数，参数相同。由类型检查保证，不另写测试。
- **参数与复数**：带参数的文案写成函数，例如 `deleted: (name: string) => …`。英文的复数用 `plural(count, 'file', 'files')`。数字和大小经 `formatNumber`，按当前语言的 `Intl` 格式输出；时长用 `common.duration`。
- **错误**：
  - 预料中、作者要处理的错误，由领域代码抛出带数据的错误（例如归档导入里不合格的路径），界面按当前语言写成句子；
  - 意料之外的错误，在当前语言的说明之后附上原文。原文是英文，面向维护者，各语言相同。
- **不翻译的**：
  - 发给模型的提示词、工具说明和工具结果，保持英文；Agent 的回复跟随作者消息的语言；
  - 预览里 SillyTavern / TauriTavern 自己的界面，跟随它们自己的语言设置；
  - 项目文件、样板、文档；
  - ST、TT、Agent、Checkpoint、Mount 等专有名词，两种语言都照写。
- **模板**：项目的起始文件用英文写，包括代码注释和 `AGENTS.md`。扩展模板里扩展自己的界面文字，经 SillyTavern 的本地化（manifest 的 `i18n` 与 `getContext().t`）同时给出中文，随预览前端的语言显示，这也是生态里扩展本地化的做法。新项目的默认名称来自 Studio 的文案。
- **只写用户此刻需要的**：
  - 标签、按钮和界面本身能说清的，不另加说明。说明只在不写就会做错时才写，一句话；
  - 不解释实现（同源、Session、数据从哪来、保留策略），不复述界面上已经看得见的状态，不写"可以……也可以……"一类的铺陈；
  - 失败写成"X 失败"或"无法 X"，后面接原因或原文。
- **语气**：
  - 中文：短句，不用"您"，不用感叹号；
  - 英文：句首大写（sentence case），平实，不用 "please"，不用感叹号。按钮写动作，如 "Export"、"Roll back to here"。
