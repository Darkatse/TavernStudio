## 阶段

**P0：运行时验证。** 用实测数据确认架构是否成立，结论回写到架构文档。见 [P0.md](P0.md)。

**P1：MVP。** 见 [P1.md](P1.md)。
- 项目：主题、前端卡、正则美化、酒馆助手脚本、基础扩展。构建方式只支持无构建和本地文件夹模式。
- 预览：
  - Vendor / Device 切换，桌面与移动可并排显示。
  - 样板库只读，可导入作者自己的卡、聊天和主题。
  - Replay。
- 编辑：CodeMirror、文件树、检查器（点击样式归属可跳转到源码）、变量面板。
- 界面：按 [UI](../UI.md) 补齐组件；中文正文字号实测后定稿；手动切换深浅色与偏好存储。
- Agent：全部工具、首批 Skill 与知识包、Checkpoint、Journal。
- 导出：全部产物格式。

**P2：**
- 浏览器内构建。
- 样板编辑器。
- Scene：样板加上一段界面操作，用来复现某个界面状态。基于它做 Vendor × Device × Scene 的矩阵截图。
- 知识包流水线自动化，加入 BM25。
- 从 GitHub 导入。

**P3：**
- 分享链接。
- 社区 Skill。
- 发布流程。
- 以 ST 扩展的形式连接用户本机实际运行的 ST / TT。

**性能**：贯穿以上阶段，分期见 [Performance §8](../Performance.md#8-分期与待验证)。
